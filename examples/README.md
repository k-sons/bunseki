# 📚 학습용 예제 모음

Code Bunseki 를 **직접 돌려 보면서** 읽는 법을 익히는 예제 5개입니다.

각 문서는 이렇게 구성돼 있습니다.

1. **붙여넣을 코드** — 앱 왼쪽 입력창에 그대로 복사
2. **먼저 스스로 예상해 보세요** — 답을 보기 전에 생각해 볼 질문
3. **앱 실행 결과** — 실제 출력 (탭별)
4. **결과 해석** — 왜 그렇게 나오는지
5. **확인 문제** — 접힌 답과 함께

> 문서에 적힌 출력값은 전부 **실제 분석기를 돌려서 얻은 것**입니다.
> 앱에서 본 화면과 다르다면 알려 주세요.

## 쓰는 법

```powershell
cd D:\bunseki\bunseki
npm run dev
```

브라우저에서 열고, 각 문서의 코드를 왼쪽에 붙여넣은 뒤 **실행**(또는 `Ctrl + Enter`)을 누르세요.

- 언어 선택은 기본값 `JSX / React` 그대로 두면 됩니다
- 결과를 확인할 탭: **동작(⚡)** 탭이 중심이고, 구조맵·메트릭은 보조로 봅니다

## 다섯 예제를 관통하는 것

동작 탭이 답하는 질문은 하나입니다.

> **이 버튼을 누르면 무슨 일이 순서대로 일어나는가?**

```
이벤트 → setter 호출 → 상태 변경 → deps 가 맞는 Effect 재실행
       → 내부 호출 / 비동기 → 또 다른 setter → 리렌더
```

- **01** 은 이 연쇄의 최소 형태(3단계)
- **02** 는 Effect 가 끼어들어 길어지는 모습
- **03** 은 상태가 훅에 있어도 이어지는 모습
- **04** 는 이어지지 **못하는** 지점과 그 이유
- **05** 는 연쇄가 과하게 길어진 나쁜 예와 고친 뒤 비교
